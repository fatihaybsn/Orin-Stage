successfully, `sudo apt install orin-stage` completed successfully, and the
installed package was confirmed to come from the PPA's Jammy source.

The session verified:

- `/usr/bin/ostg` was installed and `ostg --version` reported `ostg 0.1.0`.
- `doctor` reported 11 PASS, 0 WARN, and 0 FAIL.
- The target catalog loaded successfully.
- The PPA-installed binary opened an existing real Orin Stage state.
- JP6.2.3 target and base reuse succeeded.
- ARM64 `run` execution worked and propagated the child exit code.
- The build capsule worked and propagated the child exit code.
- `inspect` and `storage status` succeeded.
- No traceback or package-resource problem was observed.

This session reused existing, previously validated real state. It did not
create a second acquisition, base, or workspace from zero and therefore is not
a fresh-from-zero end-to-end acquisition test.

## Scope boundary

This is host operating-system acceptance, not physical Jetson hardware
validation. It does not establish GPU, DLA, camera, Jetson kernel or firmware,
flashing, performance, or other hardware-dependent fidelity.

Host acceptance also does not change JetPack target support status. In
particular, it does not make every JetPack 6 catalog entry end-to-end
supported, remove any `validation-pending` status, or claim implementation or
hardware validation for JP6.0 through JP6.2.2.
